# Паспорт проекта

## Общие сведения

| Поле | Значение |
|---|---|
| Название проекта | SuperCalculator |
| Полное название | Конфигурируемый калькулятор для автоматизации ценообразования малого бизнеса |
| Версия документа | 1.0 |
| Статус | В разработке |

## Цель проекта

Разработать веб-приложение, которое позволяет гибко настраивать ценообразование за счёт формул и справочника материалов, а также управлять правами доступа для разных пользователей. Система избавляет малый бизнес от ручного пересчёта стоимости в Excel и гарантирует актуальность цен при каждом открытии расчёта.

## Описание системы

SuperCalculator — это конфигурируемый калькулятор стоимости продуктов/услуг. Пользователь создаёт справочник **материалов** (с ценами), составляет **формулы** с плейсхолдерами вида `{группа_материала}` и `{const}`, а затем на их основе формирует **расчёты** — формулы, заполненные конкретными материалами и значениями. Итоговая стоимость пересчитывается автоматически при каждом открытии расчёта, что исключает устаревшие данные.

Приложение разворачивается отдельно для каждого клиента (компании) на их собственном сервере. Каждая компания работает со своим изолированным экземпляром системы.

## Границы проекта

### Входит в scope

- Управление справочником материалов (создание, редактирование, удаление, группировка)
- Управление формулами (конфигуратор выражений, группировка)
- Создание и редактирование расчётов на основе формул
- Система ролей и прав доступа (просмотр / создание / редактирование / удаление)
- Управление пользователями (создание, назначение ролей)
- Веб-интерфейс: страницы материалов, формул, расчётов, пользователей

### Не входит в scope

- Складской учёт количества материалов
- Интеграция с внешними системами (1С, CRM и т.д.)
- Многоарендная архитектура (SaaS) — каждый клиент имеет отдельный экземпляр
- Мобильное приложение
- Экспорт расчётов в PDF / Excel

## Ключевые требования

- Формула поддерживает плейсхолдеры `{название_группы}` (выбор материала из группы) и `{const}` (ввод числа)
- Результат расчёта пересчитывается при каждом открытии — всегда отображает актуальные цены
- Удаление формулы каскадно удаляет все расчёты на её основе
- Удаление материала, используемого в расчёте, не удаляет расчёт, но делает его невычислимым до замены позиции
- Администратор не может быть удалён из системы
- Пользователь без роли не имеет доступа ни к одной функции системы

## Ограничения

| Тип | Описание |
|---|---|
| Технические | Требуется собственный сервер клиента для развёртывания |
| Архитектурные | Система не ведёт складской учёт — только справочник цен |
| Данные | Удаление позиции прайса нарушает связанные расчёты (делает их невычислимыми) |

## Риски

| Риск | Вероятность | Влияние | Митигация |
|---|---|---|---|
| Смена бизнес-процессов клиента потребует доработки | Средняя | Высокое | Гибкая настройка формул без участия разработчика |
| Конкуренция с универсальными решениями (1С, Excel) | Высокая | Среднее | Акцент на простоте настройки и хранении данных на стороне клиента |
| Удаление материала нарушает расчёты | Низкая | Среднее | Предупреждение в UI, позиция подсвечивается как незаполненная |
