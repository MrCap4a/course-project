# Глоссарий

## Описание

Глоссарий содержит определения ключевых терминов и понятий предметной области проекта **SuperCalculator**.

## Термины

| Термин | Определение |
|---|---|
| Пользователь | Лицо, использующее систему |
| Администратор | Пользователь, обладающий всеми правами, которого нельзя удалить из системы |
| Материал | Сущность, отображающая единицу из предметной области бизнеса; хранит название, цену и единицу измерения; может использоваться в формулах |
| Группа материалов | Логическое объединение материалов для упрощения навигации |
| Формула | Готовое выражение с плейсхолдерами, в которое пользователь подставляет конкретные материалы или числа, чтобы получить расчёт |
| Группа формул | Логическое объединение формул для удобства навигации |
| Плейсхолдер | Именованная переменная внутри выражения формулы вида `{название_группы}` или `{const}`, которая при создании расчёта заменяется конкретным материалом или числовым значением |
| Расчёт | Вычисленная стоимость продукта бизнеса; формула, полностью заполненная конкретными значениями |
| Позиция | Строка внутри расчёта, связывающая один плейсхолдер формулы с выбранным материалом и его количеством либо с введённым числом для `{const}` |
| Роль | Именованный набор прав доступа для пользователя |
| Права доступа | Разрешения, определяющие, какие действия (просмотр, создание, редактирование, удаление) пользователь вправе выполнять в каждой области системы |
| Конфигуратор формул | Инструмент (модальное окно), позволяющий составлять или редактировать формулы |
| Конфигуратор материалов | Инструмент (модальное окно), позволяющий создавать или редактировать материалы |
| Окно расчёта | Инструмент (модальное окно), позволяющий посмотреть, заполнить или изменить информацию о расчёте |
| Список | Страница, отображающая все имеющиеся материалы / формулы / расчёты с фильтрацией по группам и поиском |
| Экземпляр системы | Изолированное развёртывание приложения на сервере отдельного клиента, не имеющее пересечений данных с другими развёртываниями |
