# 05 — Design

Материалы детального проектирования поведения системы **SuperCalculator** — конфигурируемого калькулятора для автоматизации ценообразования. Архитектура построена по паттерну PCMEF.

## Содержание

- [sequence-diagrams.md](sequence-diagrams.md) — диаграммы последовательности для UC-1, UC-2, UC-3 (PlantUML) + паттерны Builder, Proxy, Decorator
- [class-diagram.md](class-diagram.md) — уточнённая диаграмма классов по слоям PCMEF (PlantUML)
- [method-specifications.md](method-specifications.md) — сводная таблица и JavaDoc-спецификации ключевых методов
- [images/](images/) — изображения диаграмм (добавить вручную)

## Use-Cases

| Use-Case | Описание |
|----------|----------|
| UC-1: Добавить материал | Пользователь создаёт новый материал для расчёта стоимости товара |
| UC-2: Создать нового пользователя | Администратор регистрирует нового пользователя в системе |
| UC-3: Создать новую роль | Администратор создаёт роль с набором разрешений |

## Паттерны GoF

| Паттерн | Класс | Назначение |
|---------|-------|------------|
| Builder | `Calculation.Builder` | Пошаговое построение сложного объекта расчёта |
| Proxy | `MaterialServiceProxy`, `UserServiceProxy` | Централизованная проверка прав доступа |
| Decorator | `LoggingUserService` | Логирование действий поверх сервиса без изменения его кода |
