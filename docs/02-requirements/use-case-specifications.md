# Спецификации вариантов использования

## UC-002 — Управлять пользователями

**Актор:** Пользователь (с правами Пользователи: Создание / Удаление)

**Предусловия:** Пользователь авторизован и имеет хотя бы одно из прав на управление пользователями.

**Постусловия:** Список пользователей системы изменён (добавлен или удалён пользователь).

**Основной поток (создание):**
1. Пользователь переходит на страницу «Пользователи» → вкладка «Пользователи»
2. Нажимает «Создать пользователя»
3. Вводит имя, фамилию, логин, пароль; при необходимости выбирает роль
4. Нажимает «Сохранить»
5. Система валидирует данные и создаёт учётную запись

**Альтернативный поток — удаление:**
1. В строке нужного пользователя нажимает «Удалить»
2. Система запрашивает подтверждение
3. Пользователь подтверждает — запись удаляется
> Кнопка «Удалить» отсутствует у учётной записи Администратора

**Исключения:**
- Логин уже занят → система выводит ошибку валидации

## UC-003 — Просматривать материалы

**Актор:** Пользователь (с правом Материалы: Просмотр)

**Предусловия:** Пользователь авторизован и имеет право на просмотр материалов.

**Постусловия:** Состояние системы не изменяется.

**Основной поток:**
1. Пользователь переходит на страницу «Материалы»
2. Система отображает таблицу: Название, Группа, Цена, Единица измерения
3. Пользователь может выбрать группу в левой панели — таблица фильтруется
4. Пользователь может ввести текст в поле поиска — фильтрация по названию поверх выбранной группы

**Исключений нет.**

---

## UC-004 — Управлять материалами

**Актор:** Пользователь (с правами Материалы: Создание / Редактирование / Удаление)

**Предусловия:** Пользователь авторизован и имеет соответствующие права. Включает UC-003.

**Постусловия:** Справочник материалов изменён.

**Основной поток (создание):**
1. На странице материалов нажимает «Создать материал»
2. В модальном окне вводит: название (обяз.), цену (обяз., ≥ 0), единицу измерения (необяз.), группу (обяз.)
3. При необходимости создаёт новую группу через вложенное модальное окно
4. Нажимает «Сохранить»

**Альтернативный поток — редактирование:**
1. В строке материала нажимает «Редактировать»
2. Открывается то же модальное окно с заполненными полями
3. Изменяет нужные поля → «Сохранить»
> При изменении цены все расчёты, использующие материал, при следующем открытии отразят новую цену

**Альтернативный поток — удаление:**
1. Нажимает «Удалить» → диалог подтверждения → подтверждает
> Если материал используется в расчётах — расчёты сохраняются, но становятся невычислимыми

**Альтернативный поток — управление группами:**
1. Нажимает «Управление группами»
2. В модальном окне: создаёт, переименовывает или удаляет группы
3. При удалении группы выбирает один из вариантов: удалить вместе с материалами / перенести в группу по умолчанию / перенести в другую группу

**Исключения:**
- Название материала не уникально → ошибка валидации
- Цена < 0 → ошибка валидации

## UC-005 — Управлять формулами

**Актор:** Пользователь (с правами Формулы: Создание / Редактирование / Удаление)

**Предусловия:** Пользователь авторизован и имеет соответствующие права. Включает UC-006.

**Постусловия:** Справочник формул изменён.

**Основной поток (создание):**
1. На странице формул нажимает «Создать формулу»
2. В модальном окне вводит: название (обяз.), выражение (обяз.), группу (обяз.)
3. Выражение содержит плейсхолдеры: `{название_группы}` — для материала из группы, `{const}` — для числа
4. Пример: `({wood} + {glue}) * {const}`
5. Система отображает подсказку по синтаксису под полем выражения
6. Нажимает «Сохранить»

**Альтернативный поток — редактирование:**
1. Нажимает «Редактировать» в строке формулы
2. Вносит изменения → «Сохранить»

**Альтернативный поток — удаление:**
1. Нажимает «Удалить» → диалог с предупреждением «Все расчёты на основе этой формулы будут удалены» → подтверждает
> Все расчёты, основанные на формуле, удаляются каскадно

**Альтернативный поток — управление группами:**
Аналогично UC-004 (управление группами материалов).

**Исключения:**
- Название формулы не уникально → ошибка валидации

## UC-007 — Рассчитать цену

**Актор:** Пользователь (с правом Расчёты: Создание / Редактирование)

**Предусловия:** В системе существует хотя бы одна формула.

**Постусловия:** Расчёт сохранён с заполненными позициями и вычисленной стоимостью.

**Основной поток (создание):**
1. На странице расчётов нажимает «Создать расчёт»
2. Вводит название, выбирает базовую формулу из выпадающего списка
3. Система отображает превью выражения формулы
4. Нажимает «Создать» → открывается окно расчёта для заполнения позиций
5. Для каждого плейсхолдера `{группа}` — выбирает материал из группы и вводит количество
6. Для каждого `{const}` — вводит числовое значение
7. Система в реальном времени вычисляет итоговую сумму
8. Нажимает «Сохранить»

**Альтернативный поток — редактирование:**
1. На странице расчётов нажимает «Редактировать» в строке нужного расчёта
2. Изменяет значения позиций → «Сохранить»

**Альтернативный поток — материал удалён:**
- Позиция с удалённым материалом подсвечивается предупреждением «Материал удалён, выберите замену»
- Итоговая сумма не отображается до исправления всех позиций

**Исключения:**
- Название расчёта не уникально → ошибка валидации

## UC-008 — Посмотреть историю расчётов

**Актор:** Пользователь (с правом Расчёты: Просмотр)

**Предусловия:** Пользователь авторизован и имеет право на просмотр расчётов.

**Постусловия:** Состояние системы не изменяется.

**Основной поток:**
1. Пользователь переходит на страницу «Расчёты» (открывается по умолчанию после входа)
2. Система отображает таблицу: Название, Группа (формулы), Стоимость
3. Пользователь фильтрует по группе и/или ищет по названию
4. Нажимает «Открыть» в строке нужного расчёта
5. Система пересчитывает стоимость по актуальным ценам и отображает окно расчёта в режиме просмотра (поля заблокированы)

**Исключений нет.**

## UC-009 — Управлять ролями

**Актор:** Пользователь (с правами Роли: Создание / Редактирование / Удаление)

**Предусловия:** Пользователь авторизован и имеет соответствующие права.

**Постусловия:** Список ролей изменён; права пользователей с изменёнными ролями обновлены.

**Основной поток (создание):**
1. Переходит на страницу «Пользователи» → вкладка «Роли»
2. Нажимает «Создать роль»
3. Вводит название роли
4. В сгруппированном чеклисте выбирает права по областям:

| Область | Доступные права |
|---|---|
| Материалы | Просмотр, Создание, Редактирование, Удаление |
| Формулы | Просмотр, Создание, Редактирование, Удаление |
| Расчёты | Просмотр, Создание, Редактирование, Удаление |
| Роли | Создание, Редактирование, Удаление |
| Пользователи | Создание, Удаление |

5. Нажимает «Сохранить»

**Альтернативный поток — редактирование:**
1. Нажимает «Редактировать» в строке роли
2. Изменяет название и/или набор прав → «Сохранить»

**Альтернативный поток — удаление:**
1. Нажимает «Удалить» → подтверждает
> У пользователей с удалённой ролью роль становится NULL; они смогут войти в систему, но не будут иметь доступа ни к одной функции

**Исключения:**
- Название роли не уникально → ошибка валидации
