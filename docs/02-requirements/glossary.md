# Глоссарий

Глоссарий предметной области проекта **SuperCalculator**. Содержит 20 терминов.

## Термины предметной области

| Термин | Определение |
|---|---|
| Пользователь | Лицо, использующее систему |
| Администратор | Пользователь, обладающий всеми правами, которого нельзя удалить из системы |
| Формула | Готовое выражение, в которое пользователь может подставить необходимые материалы или значения, чтобы получить готовый расчёт |
| Материал | Сущность, отображающая единицу из предметной области бизнеса, которая может использоваться в формулах и влиять на итоговую сумму расчёта |
| Расчёт | Вычисленная стоимость продукта бизнеса |
| Группа | Множество материалов / формул / расчётов, объединённых общим логическим названием для упрощения навигации |
| Плейсхолдер | Именованная переменная внутри выражения формулы вида `{название_группы}` или `{const}`, которая при создании расчёта заменяется конкретным материалом или числовым значением |
| Позиция | Строка внутри расчёта, связывающая один плейсхолдер формулы с выбранным материалом и его количеством либо с введённым числом для `{const}` |
| Роль | Именованный набор прав доступа для пользователя |
| Права доступа | Разрешения, определяющие, какие действия (просмотр, создание, редактирование, удаление) пользователь вправе выполнять в каждой области системы |
| Конфигуратор формул | Инструмент, позволяющий составлять или редактировать формулы |
| Конфигуратор материалов | Инструмент, позволяющий создавать или редактировать материалы |
| Окно расчёта | Инструмент, позволяющий посмотреть / заполнить / изменить информацию о расчёте |
| Список | Окно, отображающее все имеющиеся материалы / формулы / расчёты |
| Экземпляр системы | Изолированное развёртывание приложения на сервере отдельного клиента, не имеющее пересечений данных с другими развёртываниями |
| Валидация | Проверка корректности данных, введённых пользователем, перед их сохранением в системе |
| Аутентификация | Процесс проверки личности пользователя при входе в систему по логину и паролю |
| Пересчёт | Автоматическое вычисление итоговой стоимости расчёта по актуальным ценам материалов при его открытии |
| Инициализация системы | Первоначальная настройка экземпляра системы, в ходе которой создаётся суперпользователь |
| Невычислимый расчёт | Расчёт, в котором одна или несколько позиций содержат удалённый материал, из-за чего итоговая стоимость не может быть определена |
