# Матрица трассировки требований

## Описание

Матрица устанавливает соответствие между бизнес-требованиями (BR) этапа 01 и вариантами использования (UC) этапа 02, обеспечивая полноту покрытия требований.

## Матрица BR → UC

| ID | Бизнес-требование | Варианты использования |
|---|---|---|
| BR-001 | Вести справочник материалов с ценами и группами | UC-003 Просматривать материалы, UC-004 Управлять материалами |
| BR-002 | Создавать и редактировать формулы с плейсхолдерами | UC-005 Управлять формулами, UC-006 Просматривать формулы |
| BR-003 | Создавать расчёты на основе формул | UC-007 Рассчитать цену |
| BR-004 | Автоматически пересчитывать стоимость при открытии | UC-007 Рассчитать цену, UC-008 Посмотреть историю расчётов |
| BR-005 | Управлять пользователями системы | UC-002 Управлять пользователями |
| BR-006 | Управлять ролями и правами доступа | UC-009 Управлять ролями |
| BR-007 | Разворачивать систему изолированно для каждого клиента | Архитектурное решение: каждый экземпляр разворачивается отдельно |
