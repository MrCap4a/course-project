# Этап 03: Архитектура

## Обзор этапа

На данном этапе спроектирована многослойная архитектура проекта на основе паттерна PCMEF, адаптированного под Enterprise-траекторию. Выбран полный стек с поддержкой двух типов клиентов - Desktop (JavaFX) и Web (браузер) - и централизованным сервером на Java Spring Boot с PostgreSQL в качестве СУБД.

Разделение на слои обеспечивает независимое развитие интерфейса и бизнес-логики. Все межслойные зависимости реализованы через явные интерфейсы-контракты, что гарантирует слабую связанность и тестируемость компонентов.

## Ключевые архитектурные решения

- Архитектурный стиль: Enterprise PCMEF (Presentation / Control / Mediator / Entity / Foundation)
- Desktop-клиент содержит Presentation + Control локально; Web-клиент — только Presentation в браузере
- Control, Mediator, Entity, Foundation централизованы на сервере (Spring Boot)
- Единая точка интеграции для всех клиентов — REST API поверх HTTPS/JSON
- Слабая связанность обеспечивается через интерфейсы: `IMaterialService`, `IUserService`, `IMaterialRepository`, `IUserRepository`
- Дополнительный слой DTO отделяет внутренние JPA-сущности от API-контрактов
