# Этап 01: Бизнес-модель

## Обзор этапа

На данном этапе выполнен анализ и описание бизнес-модели системы **Calculator** — конфигурируемого калькулятора для автоматизации ценообразования малого бизнеса. Определены ключевые участники, бизнес-процессы, ограничения и контекст проекта.

## Ключевые решения этапа

- Система разворачивается отдельно для каждого клиента (on-premise) — данные изолированы
- Ценообразование строится через формулы с плейсхолдерами и справочник материалов
- Доступ разграничивается через роли с настраиваемым набором прав
- Результат расчёта всегда актуален — пересчитывается при каждом открытии
- Стек: Java 25 + Spring (backend), React (frontend), архитектура PCMEF
