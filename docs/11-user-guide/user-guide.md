# Руководство пользователя
## Calculator — конфигурируемый калькулятор ценообразования

---

## Вход в систему

Откройте браузер и перейдите по адресу, выданному администратором (или запустите десктоп-приложение). Введите логин и пароль, нажмите **Войти**.

После успешного входа вы попадёте на страницу расчётов. Если учётная запись не имеет назначенной роли — система отобразит сообщение с просьбой обратиться к администратору.

---

## Навигация

В левой панели отображаются разделы, к которым у вас есть доступ:

- **Расчёты** — главная страница после входа
- **Материалы** — справочник материалов и их групп
- **Формулы** — список формул и групп формул
- **Пользователи** — управление учётными записями *(только при наличии прав или для суперадмина)*
- **Роли** — управление ролями и правами *(только при наличии прав или для суперадмина)*

---

## Материалы

### Просмотр списка

Перейдите в раздел **Материалы**, вкладка **Материалы**. Отображается таблица со столбцами: название, группа, цена, единица измерения.

Фильтрация:
- Выберите группу в выпадающем списке — таблица отфильтруется по группе
- Введите текст в поле поиска — фильтрация по названию (регистр не важен)

### Создание материала

Нажмите **Создать материал**. В диалоговом окне заполните:
- **Название** — обязательно, уникальное
- **Цена** — обязательно, число ≥ 0
- **Единица измерения** — необязательно (например, «кг», «м²»)
- **Группа** — выберите из списка или создайте новую прямо в диалоге

Нажмите **Сохранить**.

### Редактирование и удаление

В строке материала нажмите значок редактирования или удаления. При удалении материала, используемого в расчётах, расчёты сохранятся, но станут невычислимыми — вам потребуется заменить удалённый материал в каждом затронутом расчёте.

### Управление группами

Перейдите на вкладку **Группы**. Здесь можно создавать, переименовывать и удалять группы материалов.

При удалении группы система предложит выбор:
- **Удалить вместе с материалами** — все материалы группы будут удалены
- **Перенести в другую группу** — выберите целевую группу из списка

## Формулы

### Просмотр и фильтрация

Перейдите в раздел **Формулы**, вкладка **Формулы**. В таблице отображаются название, выражение и группа. Фильтрация аналогична разделу материалов.

### Создание формулы

Нажмите **Создать формулу**. Заполните:
- **Название** — обязательно, уникальное
- **Выражение** — математическое выражение с плейсхолдерами:
  - `{название_группы}` — при создании расчёта пользователь выберет материал из этой группы
  - `{const}` — пользователь введёт произвольное число
- **Группа** — выберите или создайте

Пример выражения: `({wood} + {glue}) * {const}`

Нажмите **Сохранить**.

> **Внимание:** удаление формулы необратимо удалит все расчёты, созданные на её основе.

### Управление группами формул

Аналогично группам материалов. При удалении группы формул каскадно удаляются все формулы группы и все расчёты, основанные на них.

---

## Расчёты

### Просмотр списка

Раздел **Расчёты** открывается по умолчанию после входа. В таблице отображаются: название, формула, выражение, группа формулы, итоговая стоимость.

Итоговая стоимость пересчитывается по актуальным ценам при каждом открытии расчёта. Если один из материалов расчёта был удалён — вместо суммы отображается «—».

### Создание расчёта

1. Нажмите **Создать расчёт**
2. Введите **Название** и выберите **Формулу** из выпадающего списка
3. Нажмите **Создать** — откроется окно заполнения позиций
4. Для каждого плейсхолдера `{группа}`:
   - Выберите материал из указанной группы
   - Введите количество
5. Для каждого `{const}` введите числовое значение
6. Система в реальном времени отображает итоговую сумму
7. Нажмите **Сохранить**

### Редактирование расчёта

Нажмите кнопку редактирования в строке расчёта. Измените значения позиций и сохраните.

### Невычислимый расчёт

Если материал в одной из позиций был удалён после создания расчёта, соответствующая позиция будет подсвечена, а итоговая сумма не будет отображаться. Откройте расчёт на редактирование, выберите замену для отмеченной позиции и сохраните.

## Пользователи *(доступно суперадмину и пользователям с правами `users.*`)*

### Список пользователей

Перейдите в раздел **Пользователи**, вкладка **Пользователи**. Таблица содержит: логин, имя, фамилию, роль.

### Создание пользователя

Нажмите **Создать пользователя**. Заполните:
- **Имя** и **Фамилия**
- **Логин** — уникальный
- **Пароль**
- **Роль** — необязательно (пользователь без роли сможет войти, но не будет иметь доступа к функциям)

### Удаление пользователя

Нажмите значок удаления. Суперадмин не может быть удалён — кнопка для него недоступна.

---

## Роли *(доступно суперадмину и пользователям с правами `roles.*`)*

### Список ролей

Перейдите в раздел **Пользователи**, вкладка **Роли**. В таблице отображаются название роли и назначенные права в виде бейджей.

### Создание роли

Нажмите **Создать роль**. Введите название и выберите права из сгруппированного списка:

| Область | Доступные права |
|---|---|
| Материалы | Просмотр, Создание, Редактирование, Удаление |
| Формулы | Просмотр, Создание, Редактирование, Удаление |
| Расчёты | Просмотр, Создание, Редактирование, Удаление |
| Роли | Создание, Редактирование, Удаление |
| Пользователи | Создание, Удаление |

Нажмите **Сохранить**.

> Право «Просмотр» для раздела **Расчёты** также открывает доступ к просмотру материалов и формул, поскольку они отображаются внутри расчётов.

### Редактирование и удаление роли

При удалении роли пользователи, которым она была назначена, теряют все права — они смогут войти, но не увидят ни одного раздела.

---

## Выход из системы

Нажмите кнопку выхода в верхнем правом углу. Токен аутентификации будет удалён, вы будете перенаправлены на страницу входа.
