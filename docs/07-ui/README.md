# Этап 07: Пользовательский интерфейс

## Обзор

На данном этапе реализованы два клиента приложения **Calculator** с идентичной функциональностью: веб-клиент на React + TypeScript и десктоп-клиент на JavaFX. Оба работают с одним бэкендом через REST API, аутентификация — JWT.

## Клиенты

| Клиент | Стек | Тип |
|---|---|---|
| Веб | React + TypeScript, React Router, JWT в localStorage | Тонкий клиент (браузер) |
| Десктоп | JavaFX | Толстый клиент (JVM) |

Presentation-слой в обоих клиентах реализует только отображение и ввод. Вся бизнес-логика централизована на сервере (слои C, M, E, F). Взаимодействие — REST API + JSON.

## Реализованные экраны

| Маршрут / Окно | Экран | Доступ |
|---|---|---|
| `/login` | Форма входа | Все (без токена) |
| `/calculations` | Расчёты (главная) | Права `calculations.*` |
| `/materials` | Материалы и группы материалов | Права `materials.*` |
| `/formulas` | Формулы и группы формул | Права `formulas.*` |
| `/users` | Пользователи | Суперадмин или права `users.*` |
| `/roles` | Роли и права доступа | Суперадмин или права `roles.*` |

Навигационная панель и разделы пользователей/ролей отображаются только при наличии соответствующих прав. Суперадмин видит всё.

## Ключевые UX-решения

- Группировка по вкладкам: материалы/группы материалов и формулы/группы формул — на одной странице
- Результат расчёта пересчитывается при каждом открытии по актуальным ценам
- Если материал в позиции расчёта удалён — результат отображается как «—», позиция подсвечивается
- Суперадмин защищён от удаления: кнопки действий для него неактивны в UI (плюс триггер на уровне БД)
- При удалении группы выводится диалог выбора стратегии (удалить / перенести)
