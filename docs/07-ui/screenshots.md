# Экраны интерфейса

Описание актуально для обоих клиентов — веб (React) и десктоп (JavaFX). Функциональность и сценарии идентичны, различается только технология отрисовки.

---

## Авторизация

Форма входа с полями «Логин» и «Пароль». После успешной аутентификации JWT-токен сохраняется, пользователь перенаправляется на главную страницу (расчёты). При неверных данных отображается сообщение об ошибке.

## Материалы `/materials`

Страница содержит две вкладки: «Материалы» и «Группы».

**Вкладка «Материалы»**

Таблица материалов с фильтром по группе и поиском по названию (case-insensitive). Каждая строка содержит кнопки редактирования и удаления. Кнопка «Создать» открывает диалог.

| Веб | Десктоп |
|---|---|
| ![Материалы (веб)](images/web/materials_page.png) | ![Материалы (десктоп)](images/desktop/materials.png) |

Диалог создания/редактирования содержит поля «Название», «Цена», «Единица измерения» и выбор группы.

|---|---|
| ![Диалог материала (веб)](images/web/new_or_edit_material.png) | ![Диалог материала (десктоп)](images/desktop/new_or_edit_material.png) |

Таблица групп материалов. При удалении группы открывается диалог выбора стратегии: удалить материалы каскадно или переместить в другую группу.

## Расчёты `/calculations`

Таблица расчётов с колонками: название, формула, выражение, группа формулы, результат. Результат пересчитывается по актуальным ценам при каждом открытии. Если хотя бы один материал в позиции удалён — результат отображается как «—».

Диалог создания: выбор формулы, затем для каждого плейсхолдера `{группа}` — выбор материала из нужной группы и ввод количества; для `{const}` — ввод числа напрямую.

## Пользователи `/users`

Таблица пользователей: логин, имя, фамилия, роль. Диалог создания/редактирования содержит поля логина, имени, фамилии, пароля и выбор роли. Суперадмины защищены — кнопки редактирования и удаления для них неактивны. Раздел виден только суперадмину или пользователям с правами `users.*`.

## Роли `/roles`

Таблица ролей: название и набор прав в виде сгруппированных бейджей. Диалог создания/редактирования содержит поле «Название» и чекбоксы прав, сгруппированные по областям: материалы, формулы, расчёты, роли, пользователи. Раздел виден только суперадмину или пользователям с правами `roles.*`.
